# Nightly Accountability Tracker

1. Open [Nightly Accountability](https://tonight-s-check-in.vercel.app/) in any modern browser.
2. Each night, tick the habits you completed and optionally add a one-line reflection. Use **+ Add another habit** whenever you want to track an additional task. Use **Edit** to change both a task title and its short description, or **Remove** to delete it. Use **+ Add subtask** beneath a habit to add its smaller checklist steps. When a habit has subtasks, its 1 point is divided equally between them—for example, five subtasks are worth 0.20 each.
3. The current date opens automatically. The history section lets you revisit earlier check-ins.
4. Select **Sign in** and use the same account on your phone and computer to synchronize changes. The app continues saving locally while offline and reconnects when internet access returns.
5. On supported phones and computers, use **Install app** near the bottom to add Nightly Accountability to the home screen or app list.
6. Installed copies update from the website whenever they are opened online. If an update arrives while the app is already open, choose **Update now** on the in-app notice.

The weekly average is calculated from the check-ins recorded in the most recent seven days. A streak counts consecutive days with a full score, ending today.

Manual backups are optional once you sign in. The collapsed **Optional data tools** section can still download or restore a private JSON copy when needed. Cloud records are protected by Supabase authentication and Row Level Security so each account can access only its own tracker row.

For branded confirmation and password-reset emails, follow [SUPABASE-EMAIL-SETUP.md](SUPABASE-EMAIL-SETUP.md).
