# Nightly Accountability Tracker

1. Open `nightly-accountability-tracker.html` in any modern browser (double-click it, or drag it into a browser window).
2. Each night, tick the habits you completed and optionally add a one-line reflection. Use **+ Add another habit** whenever you want to track an additional task. Use **Rename** or **Remove** beside any task to customize the list. Use **+ Add subtask** beneath a habit to add its smaller checklist steps. When a habit has subtasks, its 1 point is divided equally between them—for example, five subtasks are worth 0.20 each.
3. The current date opens automatically. The history section lets you revisit earlier check-ins.
4. Select **Sign in** and use the same account on your phone and computer to synchronize changes. The app continues saving locally while offline and reconnects when internet access returns.

The weekly average is calculated from the check-ins recorded in the most recent seven days. A streak counts consecutive days with a full score, ending today.

The backup controls let you download or restore a private JSON copy of the tracker. Cloud records are protected by Supabase authentication and Row Level Security so each account can access only its own tracker row.
