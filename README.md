# Nightly Accountability Tracker

1. Open `nightly-accountability-tracker.html` in any modern browser (double-click it, or drag it into a browser window).
2. Each night, tick the habits you completed and optionally add a one-line reflection. Use **+ Add another habit** whenever you want to track an additional task. Use **Rename** or **Remove** beside any task to customize the list. Use **+ Add subtask** beneath a habit to add its smaller checklist steps. When a habit has subtasks, its 1 point is divided equally between them—for example, five subtasks are worth 0.20 each. Changes save automatically in that browser on that device.
3. The current date opens automatically. The history section lets you revisit earlier check-ins.

The weekly average is calculated from the check-ins recorded in the most recent seven days. A streak counts consecutive days with a full score, ending today.

To use it on a phone, copy the HTML file to the phone (email it to yourself, use cloud storage, etc.) and open it in the phone's browser. Phone and computer histories are stored separately because the app keeps data locally.
